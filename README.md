# ESP32-Trivia-Battle

## How to Play
the ESP32 connects to the internet via Wi-fi and retrieves trivia questions from an online API.A question appears on the screen, and both players have the chance to answer. Each player has a button in front of him ,and whoever pushes it first has the opportunity to give an answer through a physical keyboard in a time interval of 10 seconds which will be displayed on a seven-segment display. If the player gives the wrong answer the opponent can give an answer . If someone gives a correct answer a green led will light up else a red one will .The player who answers correctly wins a point then it goes to the next round .If no one answers correctly , the game will also go to the next round ,but no one will receive a point. First to 7 points wins

## Components
-TFT/LCD Display
-Physical Keyboard
-Push buttons 
 -Buzzer
 -Seven-Segment Displays
 -Green LED
 Red LED
